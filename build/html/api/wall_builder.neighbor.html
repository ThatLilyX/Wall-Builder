wall_builder.neighbor module

This module contains algorithms for finding the eligible neighbors of each row layout.

wall_builder.neighbor.build_neighbors(row_layouts: ~typing.List[~typing.List[int]], predicate: ~typing.Callable = <function no_common_edge>) → Dict[int, List[int]][source]

Return a dictionary mapping each layout’s index to its eligible neighbors’ index.

The runtime complexity is O(K^2) where K is the number of row layouts. The memory complexity is O(K^2) where K is the number of row layouts.

Parameters:

  • row_layouts (List[List[int]]) – a list of row layouts

  • predicate (Callable, optional) – the predicate for eligible neighboring rows. Defaults to no_common_edge.

Returns:

a dictionary mapping each layout’s index to its eligible neighbors’ index

Return type:

Dict[int, List[int]]

Helper function to calculate cumumative sum of length for each row layout.

wall_builder.neighbor.no_common_edge(i: int, j: int, cum_sums: Dict[int, List[int]]) → bool[source]

Return True if the layouts at indices i and j have a common edge. Cum_sum for each row layout is pre-calculated to avoid repeated calculations. If the cum_sum of two row layouts have a common element except for the last one, then the two layouts have a common edge.
